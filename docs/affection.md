# 好感度规则

## 存档键

```text
(cardId, qq)
```

一张角色卡 × 一个 QQ 一份存档。A 和 B 不共享；同一个 QQ 的不同角色卡也不共享。

身份分支（普通人 / 陈汉升）不拆存档，只存在这条线的 `identityId` 字段里。好感度不因身份切换而重置。

## 数值

- 范围：0–100，隐藏，不向用户显示。
- 初始值：卡里的 `affection.initial`，沈幼楚为 0。
- 任何用户、管理员、后台接口都不能直接改数值。
- 唯一人工操作：重置某个 QQ；删除整条 `(cardId, qq)` 存档，回到初始状态。

## 上涨

由角色卡配置，默认值：

| 事件 | 变化 | 说明 |
|---|---:|---|
| 有效聊天 | +0.2 | 有内容的来回，不是单字刷屏 |
| 用户说自己 | +2 | 主动讲自己的事、真实处境 |
| 帮忙/守约/记住细节 | +2 | 用户帮到她，或兑现承诺 |
| 关键共同事件 | +3 | 剧情上有分量的事 |
| 单日上限 | +8 | 防止刷分 |

单次事件变化限制在 `-10 ~ +5`；超过由引擎截断。

## 下降

| 事件 | 变化 |
|---|---:|
| 冲突/冒犯 | -5 |
| 越界/雷区 | -10 |
| 长期不聊 | 3 天后每天 -1，最低 0 |

衰减按现实自然日计算，不按消息条数。后台 20 分钟静默推进不会额外加减好感。

## 阶段与解锁

沈幼楚卡：

| 阶段 | 区间 | 表情包 | 语音 | 照片 |
|---|---:|---:|---:|---:|
| 陌生 | 0–19 | 否 | 否 | 否 |
| 眼熟 | 20–44 | 否 | 否 | 否 |
| 说上话 | 45–69 | 是 | 否 | 否 |
| 亲近 | 70–89 | 是 | 是 | 否 |
| 交心 | 90–100 | 是 | 是 | 是 |

“是”只代表允许调用对应工具；角色仍然可以按语境、心情、边界拒绝。低于阈值时，桥接层硬拒绝，不靠模型自觉。

## 更新方式

好感度由 AI 根据互动事件评估，桥接层做三件事：

1. 单次变化截断。
2. 单日上涨封顶。
3. 按自然日计算衰减。

不提供“设置好感”“加好感”“减好感”的后台接口；只有重置。

## 背景推进

- 每 20 分钟一次，静默。
- 每个 `(cardId, qq)` 独立推进，互不串线。
- 只更新剧情、心情、事件、日记、关系阶段等叙事状态。
- 不主动发消息，不直接加好感。
- 不设 token 上限；需要记录消耗，便于排查，但不做硬拦截。

## 重置

重置某个 QQ 时删除：

- 好感度
- 聊天记忆
- 剧情进度
- 关系状态
- 背景事件/日记
- 运行时生成的照片、语音缓存

保留：

- 角色卡本体
- 卡自带形象图、语音素材
- 其他 QQ 的存档

重置后从卡初始状态开始，沈幼楚好感为 0、剧情从开头走。
