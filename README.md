# QQ Role Cards

角色卡仓库。每张卡是一个可导入后台的独立角色包：人设、行为、好感度、运行配置、形象素材，语音后续接入。

这个仓库只管“角色卡是什么”，不直接跑 QQ 机器人。后台导入后，才把卡变成可用的角色。

## 一张卡包含什么

```text
cards/<id>/
  card.json        # 卡的身份、好感度、节奏、身份分支、素材索引
  persona.md       # 人设正文：她是谁、怎么说话、边界
  behavior.md      # 这张卡自己的行为预设（不替代全局工具协议）
  examples.md      # 对话样例：只学语气/节奏，不照抄
  assets/          # 角色形象图；用户后续生成
  voice/           # 语音素材/音色引用；先留空
```

`card.json` 里的运行配置是**卡自带的默认值**。导入后运行时只读，后台不提供手调主动间隔、表情概率、好感阈值这些入口；普通自设模式仍然走原来的后台配置，两套系统互不覆盖。

## 沈幼楚 · 当前默认值

好感度 0–100，初始 20，隐藏，不显示数值。每个“角色卡 × QQ”一份，A 和 B 不共享；身份线不改变好感度，只改变剧情关系。

| 阶段 | 区间 | 解锁 |
|---|---:|---|
| 陌生 | 0–19 | 只文字 |
| 眼熟 | 20–44 | 只文字 |
| 说上话 | 45–69 | 表情包 |
| 亲近 | 70–89 | 语音 |
| 交心 | 90–100 | 照片 |

- 每轮有效聊天基础 +0.2，单日最多 +5。
- 用户主动说自己的事 +2；帮忙、记住细节、守约 +2；关键共同事件 +3。
- 冲突 -5；越界 -10；单次事件限制在 -10 ~ +5。
- 3 天没有互动后，每天 -1，最低 0。
- 后台不能改数值，只能重置某个 QQ；重置会把这条线的记忆、好感、剧情、关系、背景状态全部清掉，回到初始 20。
- 解锁只是“允许”，不是“必须发”；角色仍可按语境和情绪拒绝。

### 回复概率

| 好感度 | 回复概率 |
|---:|---:|
| 0 | 1% |
| 1–4 | 5% |
| 5–9 | 5% 到 25% 线性 |
| 10–19 | 30% |
| 20 以上 | 100% |

### 主动消息

低于 40 不主动。到 40 后按区间随机：

| 好感度 | 主动间隔 |
|---:|---|
| 40–49 | 24–30 小时 |
| 50–59 | 16–20 小时 |
| 60–69 | 10–14 小时 |
| 70–79 | 6–9 小时 |
| 80–89 | 4–6 小时 |
| 90–94 | 3–4 小时 |
| 95–100 | 2–3 小时 |

主动消息还有三条硬限制：用户 30 分钟内说过话不发；上一条主动消息没回不叠下一条；00:00–07:00 不发。

详细规则见 [docs/affection.md](docs/affection.md)。

## 独立记忆

角色卡模式有自己的一条记忆，不读普通人格的记忆，也不把普通会话的历史带进来：

- 每条「卡 × QQ」一份：`state/role-cards/<cardId>/<qq>/memory.json`。
- 记三类东西：对方明确说过的长期事实、你们之间发生过的片段、最近几句对话。
- 每次注入只带最近少量事实和对话，不把整份聊天记录倒给模型；用不用、提不提，按当前话题自然决定。
- 后台每 20 分钟的生活日记也会作为「她那边的日子」进入记忆，不和聊天事实混在一起。
- 重置这条线会删掉 `memory.json` 和运行时缓存，其他 QQ、卡本体不动。
- 面板「角色卡模式」里可以只读查看每条线记得什么。

## 对话样例与开场

`card.json` 的 `dialogue` 可以带：

- `stageHints`：每个关系阶段该怎么说话，按人物自己的节奏，不按固定台词。
- `openingHints`：第一次接话、隔几天回来、只收到「在吗」时怎么开。
- `examples`：`examples.md`，给模型学语气和停顿；样例不是固定回复。

## 后台推进

- 每 20 分钟静默推进一次，不主动发消息。
- 不设 token 上限；按“角色卡 × QQ”独立跑。
- 背景推进只改剧情、心情、事件、日记等状态，不直接加好感；好感只由互动和长期不聊的衰减改变。
- 用户不在时，角色照常生活、成长、走自己的时间线。

## 身份分支

`card.json` 的 `identityBranches` 只描述“用户是谁”带来的关系/叙事分支，不拆好感度存档。

- 用户没有明确说身份：默认普通人线。
- 用户明确说“我是陈汉升”：锁定为陈汉升线，不能改口。
- 锁定身份不等于自动走小说剧情；只有用户的实际行为命中关键事件，才向原著节点靠。
- 好感度两条身份线共用同一个值。

## 新增一张卡

1. 复制 `cards/shenyouchu/` 为 `cards/<新id>/`。
2. 改 `card.json` 的 `id`、`name`、`version`、阈值、节奏。
3. 写 `persona.md`、`behavior.md`、`examples.md`。
4. 在 `card.json` 里补 `dialogue.stageHints` / `openingHints` / `examples`。
5. 把形象图放进 `assets/`，语音素材放进 `voice/`。
6. 跑：

```bash
npm run validate
```

校验通过后提交。后台导入时按 `card.json` 建独立存档，不会覆盖已有的同名卡。

## 边界

- 不把用户私聊内容、QQ 号、记忆写进这个仓库。
- 角色卡素材可以进仓库；运行时生成的照片/语音缓存不进。
- 角色卡是个人角色设定，仓库保持私有。
